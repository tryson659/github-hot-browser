# 筛选语义

## 组合方式

语言、领域、标签是 **交集（AND）**，不是并集：

```
结果 = 热门池 ∩ 语言(单选) ∩ 领域(单选) ∩ 标签(单选) ∩ 关键词
```

- **语言**：单选。点 C++ 只显示当前热门池里的 C++；再点一次取消。
- **领域**：单选，与语言叠加。
- **标签**：单选，与语言/领域叠加；清除筛选会全部重置。
- **关键词**：在名称/描述/备注/分类等字段上再收窄。
- 设置中的“语言抓取通道/领域抓取通道”是**抓取哪些通道**，不是同时选中的筛选项；
  两者不要混淆。

## 侧栏计数

- “全部语言”= 当前热门池条数（不是各语言通道缓存之和）。
- C++ / C / Python 等行数 = 当前热门池中该语言/领域的条数。
- 因此不会再出现“全部语言 0，但右侧有 33 条”的矛盾；API 关闭、只抓了 Trending
  时也能正确显示当前池分布。
- 未跟踪但出现在当前池的语言/领域也会列在侧栏，点击可筛。

## 标签

- 卡片标签优先来自仓库 topics；没有 topics 时读取 `repo_topics` 缓存。
- “🏷 补齐当前列表标签”经 ecosyste.ms 抓取并缓存 7 天；补齐后下拉和卡片标签
  会刷新，可直接点击筛选。
- 标签下拉候选合并 DB 缓存，不要求卡片自身带 topics；因此补齐后不再出现
  “只有（全部标签）”。
- 标签不是 GitHub topics 的替代：用户标签、分类、GitHub topics 分开保存。

## 仍未支持

- 多语言并集（同时选 C++ 和 C）目前不支持；语言只能单选。
- 多标签并集/排除条件不支持。
- 若需要多选并集，需要把侧栏改成多选并调整过滤谓词；当前先保持单选可预测。
